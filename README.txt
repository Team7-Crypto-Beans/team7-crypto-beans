# Team 7 Crypto Beans website

A responsive static website for Netlify. The supplied 10-second Jerry Beans Man MP4 is used as the looping, muted hero video.

## Publish with Netlify
1. Extract this ZIP.
2. In Netlify, choose **Add new site** → **Deploy manually** (or drag the extracted `team7-crypto-beans-site` folder into the deploy area).
3. The published site will receive a `netlify.app` address.
4. For GitHub-based deploys, upload the contents of this folder to the root of the `Team7-Crypto-Beans/team7-crypto-beans` repository, then connect that repository in Netlify.

## Files
- `index.html` — page content and project links
- `styles.css` — responsive galaxy/portal styling
- `script.js` — mobile navigation and portal detail popups
- `assets/jerry-beans-man.mp4` — supplied 10-second animation
- `assets/jerry-poster.jpg` — video poster / fallback

## Before launch
- Add the Discord invite URL when the Discord server is ready.
- The community poll currently directs visitors to the Telegram group. A genuinely shared, live website poll needs a poll provider/backend or an embed; this static site does not pretend local clicks are public votes.
- Confirm the final public token link and any project details before launch.
